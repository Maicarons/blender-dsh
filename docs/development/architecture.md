# 架构

## 系统架构

```
┌─────────────────────────────────────────────────────┐
│                   AI Agent                           │
│  (通过自然语言调用 blender_* 工具)                    │
└──────────────┬──────────────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────────────┐
│              DSH Host 插件 (host.js)                  │
│                                                      │
│  ┌─────────────┐  ┌─────────────┐  ┌──────────────┐ │
│  │blender_exec │  │blender_create│  │blender_modify│ │
│  ├─────────────┤  ├─────────────┤  ├──────────────┤ │
│  │blender_scene│  │blender_info │  │  RPC Handler │ │
│  └─────────────┘  └─────────────┘  └──────────────┘ │
│                                                      │
│  ┌──────────────────────────────────────────────────┐│
│  │        Blender 执行引擎 (subprocess.spawn)        ││
│  └──────────────────────────────────────────────────┘│
└──────────────┬──────────────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────────────┐
│          Blender --background --python-expr           │
│                                                      │
│  ┌─────────────┐  ┌─────────────┐  ┌──────────────┐ │
│  │     bpy     │  │    bmesh    │  │  mathutils   │ │
│  └─────────────┘  └─────────────┘  └──────────────┘ │
│                                                      │
│  Python 脚本执行 → JSON 结果输出 (stdout)             │
└─────────────────────────────────────────────────────┘
```

## 执行流程

1. AI Agent 调用 blender_* 工具
2. Host 插件构建 Python 脚本，Base64 编码
3. 通过 `subprocess.spawn` 启动 Blender 后台进程
4. Blender 执行脚本，输出 JSON 结果到 stdout
5. 插件解析 JSON，返回给 Agent

## 关键技术

- **Base64 编码**：避免命令行转义问题
- **JSON 错误处理**：try/except 包裹脚本，错误信息序列化
- **超时机制**：Promise.race 对超时进程发送 SIGTERM
- **自动清理**：插件停止时所有子进程自动终止
