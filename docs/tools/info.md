# blender_info

查询场景信息。

## 查询类型

### scene_summary — 场景概览
返回场景名称、对象数量、相机、渲染引擎和分辨率。

### object_list — 对象列表
返回所有对象的名称、类型、位置和顶点数。

### object_info — 对象详情
需要 `object` 参数，返回指定对象的详细信息：
- 名称、类型、位置、旋转、缩放
- 顶点数、面数
- 修改器列表、材质列表

### object_tree — 对象树
返回场景层次结构，包含父/子关系。

### material_list — 材质列表
返回所有材质的名称和节点数。

### stats — 统计信息
- 总对象数、网格数、材质数
- 总顶点数、总面数
- 灯光数、相机数

### render_settings — 渲染设置
- 渲染引擎、分辨率
- 文件格式、色彩模式
- Cycles 采样数、降噪设置
