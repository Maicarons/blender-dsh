# blender_create

Create 3D objects.

## Supported Types

`cube`, `sphere`, `cylinder`, `cone`, `torus`, `ico_sphere`, `monkey`, `plane`, `circle`, `grid`, `text`, `custom_mesh`, `bezier_curve`

## Parameters

| Param | Type | Description |
|-------|------|-------------|
| `type` | string | Object type |
| `name` | string | Object name |
| `location` | [x,y,z] | Position |
| `rotation` | [x,y,z] | Rotation (radians) |
| `scale` | [x,y,z] | Scale |
| `size` | number | Size |
| `radius` | number | Radius |
| `depth` | number | Depth/height |
