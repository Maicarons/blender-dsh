# blender_modify

Modify 3D objects.

## Operations

| Operation | Description |
|-----------|-------------|
| `transform` | Change location/rotation/scale |
| `modifier` | Add/apply modifier |
| `material` | Create and assign PBR material |
| `boolean` | Boolean operation |
| `shade_smooth` / `shade_flat` | Smooth/flat shading |
| `join` | Join selected objects |
| `duplicate` | Duplicate with offset |
| `delete` | Delete object |
| `origin_set` | Set origin to geometry center |
