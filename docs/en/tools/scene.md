# blender_scene

Scene management.

## Operations

| Operation | Description |
|-----------|-------------|
| `clear` | Clear all objects |
| `light_add` | Add light (POINT/SUN/SPOT/AREA) |
| `camera_add` | Add camera with target |
| `ground_add` | Add ground plane |
| `render` | Render scene to image |
| `render_settings` | Configure render settings |
| `world_set` | Set world background |
| `export` | Export scene (OBJ/FBX/GLB/STL/PLY) |
