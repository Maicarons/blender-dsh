# blender_info

Query scene information.

## Queries

| Query | Description |
|-------|-------------|
| `scene_summary` | Scene overview |
| `object_list` | List all objects |
| `object_info` | Detailed object info (requires `object` param) |
| `object_tree` | Scene hierarchy |
| `stats` | Scene statistics |
| `render_settings` | Render configuration |
