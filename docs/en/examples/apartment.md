# Apartment Building

Procedural 12-story apartment building.

```
> Generate a 12-story apartment building with windows, balconies and entrance
```

## Parameters

| Parameter | Value |
|-----------|-------|
| Floors | 12 |
| Floor height | 3.0m |
| Total height | 36m |
| Width | 18m |
| Depth | 12m |

## Details

- Windows on all sides
- Balconies every 3 floors
- Glass entrance + canopy
- Roof decorations

Files: `output/apartment.blend`, `output/apartment_render.png`
