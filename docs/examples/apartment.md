# 公寓楼

使用 Blender 程序化生成 12 层公寓楼模型。

## 对话示例

```
> 使用 blender_execute 生成一个 12 层公寓楼，带窗户、阳台和入口
```

## 建筑参数

| 参数 | 值 |
|------|-----|
| 层数 | 12 |
| 层高 | 3.0m |
| 总高 | 36m |
| 宽度 | 18m |
| 深度 | 12m |

## 包含的细节

- 每层前后各 4 扇窗户，侧面各 2 扇
- 每 3 层一个阳台（带栏杆和玻璃围栏）
- 一楼入口玻璃门 + 雨棚
- 楼层分隔线
- 屋顶装饰结构
- SUN + Area 灯光
